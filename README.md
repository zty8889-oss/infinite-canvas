# AI漫剧工作台 · Infinite Canvas

AI漫剧制作工具，纯前端单文件、零依赖、离线可用。

线上：
- 🎬 分镜模式（故事板）：https://zty8889-oss.github.io/infinite-canvas/
- 🧩 节点模式（工作流）：https://zty8889-oss.github.io/infinite-canvas/node.html

## 🎬 分镜模式 index.html
分镜卡 / 角色卡 / 场景卡 / 便利贴 / 文本 / 图片；自动镜号；导出分镜表 CSV；导出整图 PNG；Prompt 一键复制；图片粘贴。卡片支持缩放，画布支持平移和缩放；可用 Ctrl+Z / Ctrl+Y 撤销与重做。

## 🧩 节点模式 node.html（LibTV 风格）
节点式无限画布工作流：

- 节点类型：📝剧本 · 🧑角色卡 · 🎬分镜卡 · 🏞场景卡 · 🖼图像 · 🎞图生视频 · 🔊配音 · 🔗合成 · ✏️文本 · 📤上传
- 双击画布 / 输入「/」→ 节点菜单
- 端口连线（右侧输出 → 左侧输入），数据自上而下流转
- 单击节点 → 节点下方出现 LibTV 风格创作编辑器：顶部操作条、大段描述区、底部厂商 / 模型 / 类型 / 比例 / 时长工具条和圆形运行按钮；拖动或缩放节点时编辑器同步跟随
- 节点底部「＋下方添加」可在当前节点下方创建子节点；角色卡、分镜卡、场景卡支持一键向下生成并自动连线
- API 接入中心：按文本、图片、视频、语音、本地与自建筛选，每个服务商使用独立配置卡片。可分别填写 Base URL、Key、模型和额外参数，并将任意服务商设为对应能力的默认线路。
- 已提供本地模拟、OpenAI、硅基流动、火山方舟、ComfyUI 本地和自定义 OpenAI 兼容模板；可灵、LiblibAI 保留独立接入位。Key 仅存本地，不随工作流导出。
- 自定义 OpenAI 兼容模板支持文本 `/chat/completions` 与图片 `/images/generations`，可一次配置独立文本模型、图像模型和额外请求头，便于接入其他厂家模型。
- ComfyUI 本地生成默认连接 `http://127.0.0.1:8188`。从 GitHub Pages 使用时，需在 ComfyUI 启动设置中只允许 `https://zty8889-oss.github.io` 这一来源，并按浏览器提示允许本地网络访问；不要使用通配来源 `*`。
- 导出/导入工作流 JSON（不含 Key）
- Ctrl+Z / Ctrl+Y 撤销与重做；清空画布也可撤销
- 导入 JSON 会先校验结构、节点类型、数量及坐标；单文件上限 20 MB
- 本地存储超额时显示提示；请导出 JSON 备份或移除大型图片/视频

### 厂商适配层
`PROVIDERS` 注册表 + 统一协议：每个厂商实现 `run(ctx)` 或声明 `endpoint/parse`（同步）、`async/pollUrl/pollParse`（异步提交-轮询）。
未配置 Key 时用「本地模拟」可跑通全流程。已接入的线上服务会受对应厂商的 API、跨域策略、模型和计费权限限制；模板服务尚不能运行。
