# AI漫剧分镜台 · Infinite Canvas

单文件、零依赖的无限画布工具，专为 **AI漫剧制作** 设计（纯前端）。

线上：https://zty8889-oss.github.io/infinite-canvas/

## 卡片类型
- 🎬 **分镜卡**：镜号 / 景别 / 运镜 / 时长 / 画面Prompt / 台词旁白 / 参考角色 / 首帧图
- 🧑 **角色卡**：角色名 + 定妆图 + 人物一致性 Prompt
- 🏞 **场景卡**：场景名 + 参考图 + 风格 Prompt
- 🗒 便利贴 / ±文本 / 🖼 图片

## 功能
- 无限平移缩放（滚轮 / 双指捏合，以鼠标为中心）
- 拖右侧圆点连线；角色/场景 → 分镜自动建立「引用」
- 🔢 自动镜号（按左→右顺序）
- ⬇ 导出分镜表 CSV（镜号｜景别｜运镜｜时长｜画面Prompt｜台词｜参考角色｜角色一致性Prompt）
- ⬇ 导出整图 PNG
- 📋 Prompt 一键复制、Ctrl+V 粘贴图片、拖入图片
- 导入/导出 JSON，localStorage 自动保存，适应视图

打开 index.html 即可用（离线可用）。
