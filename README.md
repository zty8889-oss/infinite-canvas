# AI漫剧工作台 · Infinite Canvas

AI漫剧制作工具，纯前端单文件、零依赖、离线可用。

## Windows 桌面版（正式交付）
- 后续功能以 Windows x64 桌面版作为正式用户版本；网页保留为预览和兼容入口。
- 开发环境安装 Node.js 24 和 npm，运行 `npm install`；每次发布前更新 `package.json` 版本号并推送 `v<版本>` 标签，GitHub Actions 会构建 Windows 安装包并发布更新清单。
- 从 1.0.3 开始，桌面工具栏提供「软件更新」；点击后检查并下载新版本，下载完成后点击「重启并安装」。
- 1.0.2 及更早版本还没有更新器，需要手动安装一次 1.0.3；之后的升级可在软件内完成。本机工作流、API 配置和媒体文件保存在 `%APPDATA%\InfiniteCanvasDesktop`，升级与卸载默认保留这些数据。
- 本地构建使用 `npm run dist:win`，安装包生成在 `dist/InfiniteCanvas-<版本>-x64-Setup.exe`。
- 桌面程序使用独立窗口，模型列表读取与方舟 API 通过只监听本机回环地址的受限转发服务访问；API Key 不写入项目文件，也不会随工作流导出。
- Windows 桌面版使用体验：安装后从桌面或开始菜单启动；首次使用时需在桌面版中重新填写 API Key，因为它与浏览器网页配置分开保存。

### 版本号规则
小版本号以 10 为上限：`v1.0.10` 之后是 `v1.1.1`，`v1.1.10` 之后是 `v1.2.1`，依次类推。第三个数字超过 10 时进位到第二个数字并重置为 1。

## 🎬 分镜模式 index.html
分镜卡 / 角色卡 / 场景卡 / 便利贴 / 文本 / 图片；自动镜号；导出分镜表 CSV；导出整图 PNG；Prompt 一键复制；图片粘贴。卡片支持缩放，画布支持平移和缩放；可用 Ctrl+Z / Ctrl+Y 撤销与重做。

## 🧩 节点模式 node.html（LibTV 风格）
节点式无限画布工作流：

- 节点类型：📝剧本 · 🧑角色卡 · 🎬分镜卡 · 🏞场景卡 · 🖼图像 · 🎞图生视频 · 🔊配音 · 🔗合成 · ✏️文本 · 📤上传
- 双击画布 / 输入「/」→ 节点菜单
- 初次使用为全空画布；左键拖动框选节点，Shift 可追加选择，多选后可整体移动或删除；右键画布创建节点，右键已有节点创建并自动连接下游节点
- 图片与视频节点切换比例时，预览框尺寸同步变化；节点连接线带青蓝辉光和流动动画
- 端口连线（右侧输出 → 左侧输入），数据自上而下流转
- 单击节点 → 节点下方出现 LibTV 风格创作编辑器：顶部操作条、大段描述区、底部厂商 / 模型 / 类型 / 比例 / 时长工具条和圆形运行按钮；拖动或缩放节点时编辑器同步跟随
- 节点底部「＋下方添加」可在当前节点下方创建子节点；角色卡、分镜卡、场景卡支持一键向下生成并自动连线
- API 接入中心：按文本、图片、视频、语音、本地与自建筛选，每个服务商使用独立配置卡片。填写 Base URL 和 Key 后可从上游读取模型，点击模型即可设为该能力的默认线路。
- 已提供 OpenAI、硅基流动、火山方舟、ComfyUI 本地和自定义 OpenAI 兼容模板；可灵保留待适配接入位。Key 仅存本地，不随工作流导出。
- 自定义 OpenAI 兼容模板支持文本 `/chat/completions` 与图片 `/images/generations`，可读取 `/v1/models` 并分别选择文本、图像模型，也支持额外请求头。
- ComfyUI 本地生成默认连接 `http://127.0.0.1:8188`。从 GitHub Pages 使用时，需在 ComfyUI 启动设置中只允许 `https://zty8889-oss.github.io` 这一来源，并按浏览器提示允许本地网络访问；不要使用通配来源 `*`。
- 导出/导入工作流 JSON（不含 Key）
- Ctrl+Z / Ctrl+Y 撤销与重做；清空画布也可撤销
- 导入 JSON 会先校验结构、节点类型、数量及坐标；单文件上限 20 MB
- 本地存储超额时显示提示；请导出 JSON 备份或移除大型图片/视频
- 画布工具 API：`window.infiniteCanvas` 提供 17 个原子操作（读取/新增/连线/移动/整理/运行/撤销），支持字段裁剪与游标分页，便于外部 Agent 或脚本驱动画布

### 画布工具 API（1.0.8 新增）
`node.html` 在 `window.infiniteCanvas` 上暴露一组原子操作，外部 Agent、脚本或浏览器控制台都可以直接驱动画布：

- 读：`getCanvas` / `findNodes` / `getNode` / `getNodes` / `getEdges`，支持 `fields` 字段裁剪与 `limit` / `cursor` 游标分页
- 写：`addNode` / `updateNode` / `connectNodes` / `deleteEdges` / `deleteNodes` / `moveNodes` / `selectNodes` / `arrangeCanvas` / `fitCanvas` / `runNode`
- 历史：`undo` / `redo`，所有写操作都会进入撤销栈
- 发现：`infiniteCanvas.listTools()` 返回操作清单（名称、说明、参数），`infiniteCanvas.run(name, args)` 统一调用
- 事件：每次改动在 `document` 上派发 `infinitecanvas:change`，`detail` 含 `action` 与参数

```js
infiniteCanvas.addNode({ type: "script", x: 0, y: 0, params: { topic: "雨夜追车" } });
infiniteCanvas.arrangeCanvas();
infiniteCanvas.fitCanvas();
```

工作流文件同时加入自描述头 `format: { name: "infinite-canvas", version: 3 }`；旧版本读取时忽略该字段，仍能正常打开。

### 厂商适配层
`PROVIDERS` 注册表 + 统一协议：每个厂商实现 `run(ctx)` 或声明 `endpoint/parse`（同步）、`async/pollUrl/pollParse`（异步提交-轮询）。
生成需要先配置可用的模型服务。已接入的线上服务会受对应厂商的 API、跨域策略、模型和计费权限限制；模板服务尚不能运行。

### Ubuntu 局域网部署
- 画布可部署在 Apache 的 `/infinite-canvas/` 路径；访问 `http://192.168.2.19/infinite-canvas/node.html` 时，方舟请求会经同一服务器转发，绕过 GitHub Pages 的浏览器跨域限制。
- Apache 配置模板位于 `deploy/apache-infinite-canvas-ark-proxy.conf`，仅转发方舟模型列表、图片生成、视频任务创建与查询，并限制为 `192.168.2.0/24` 局域网访问。
- 浏览器按网站来源分别保存配置。首次打开 Ubuntu 地址时，需要重新填写方舟 Key，再点击“从上游获取”选择模型；Key 仍保存在当前浏览器的 localStorage。
